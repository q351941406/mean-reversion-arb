# 02 · 方法论:合成数据、OU 建模、Kalman 对冲与回测口径

> 本文档给出完整数学设定与实现细节,对应代码 `mrarb/`。所有估计均为**点内(point-in-time)**:t 日决策只用 ≤ t 的信息。

## 1. 合成宇宙(`synth.py`)

### 1.1 因子模型

资产对数价格:

```
Δlog P_i,t = β_m,i · F_t + β_s,i · G_{s(i),t} + ε_i,t
```

- `F_t` 市场因子,`G_t` 行业因子(s(i) 为资产所属行业),`ε_i,t` 特质噪声;
- `F, G` 为 **GARCH(1,1)** 波动的日收益:`σ_t² = ω + α ε_{t-1}² + β σ_{t-1}²`,标准 innovated 用 **t(ν=5) 标准化**(除以 √(ν/(ν−2)) 保持单位方差)→ 厚尾 + 波动聚集;
- 因子上叠加**泊松跳跃**:以概率 p 叠加 N(0, jump_scale) 冲击;
- `ε` 用 t(5) 厚尾,σ_id = 1.2%/日。

默认参数(`config.UniverseConfig`):30 资产 / 5 行业 / 1500 天,β_m ∈ [0.6, 1.5],σ_m = 1.0%,σ_s = 0.6%。

### 1.2 植入协整对(ground truth)

每个行业抽 2 资产构成配对,伙伴价格由锚定价格**构造性**生成:

```
log P_B,t = α + β·log P_A,t + s_t
s_t = a·s_{t-1} + σ_eq·√(1−a²)·z_t,   a = e^{−κ},  半衰期 = ln2/κ
```

- κ 由半衰期 ∈ [10, 25] 天抽得,σ_eq ∈ [1%, 2%](对数单位);
- 精确离散化保证 Var(s_t) = σ_eq²(平稳);
- **协整由构造成立**(残差 s_t 平稳),β_true 已知 → 筛选器召回/查准可客观评分;
- 其余 20 个资产只共享因子、特质项为随机游走成分 → 高度相关但**不**协整,是筛选器的"干扰项"。

### 1.3 制度断裂(模拟样本外失效)

按 `break_fraction`(默认 0.4)抽取的植入对,在 `break_point`(= 训练/测试边界)后价差切换为:

```
s_t = s_{t-1} + 漂移(±0.015·σ_eq) + 1.5·σ_eq·z_t
```

即协整关系死亡、价差发散——PEP-KO 式失效([2609.35359](https://arxiv.org/abs/2609.35359))。**筛选发生在断裂之前(训练期),所以策略必然选到断对**;这是刻意设计,用于检验交易规则的生存能力。

## 2. OU 校准(`ou.py: fit_ou`)

对价差样本 `{S_t}`,AR(1) 回归:

```
S_{t+1} = a·S_t + b + ε_t          (OLS)
κ  = −ln(a)/Δt,      μ_OU = b/(1−a)
Var(ε) = σ_eq²·(1−a²)   ⟹   σ_eq = √( Var(ε) / (1−a²) )
半衰期 = ln2 / κ
```

> ⚠️ **实现警示**:我们最初按 Columbia 论文 PDF 里的公式 `σ = sd(ε)·√(2κ/(1−a²))` 实现——该式在 PDF 中被排版/OCR 损坏,正确关系是 `Var(ε) = σ_eq²(1−a²)`(由 `Var(ε) = σ²/(2κ)·(1−e^{−2κ})` 与 `σ_eq² = σ²/(2κ)` 直接得到)。抄错会让 σ_eq 缩小约 2.4 倍(κ≈0.06 时),z-score 同比放大 → 每天频繁触发假信号,换手爆炸、胜率跌到 10-25%。**教训:论文公式务必从 SDE 自行推导核对一遍。**

## 3. Kalman 动态对冲(`ou.py: kalman_hedge_ratio`)

状态空间(随机游走回归,[0808.1710](https://arxiv.org/abs/0808.1710)):

```
状态:  θ_t = [α_t, β_t]ᵀ,   θ_t = θ_{t-1} + w,   w ~ N(0, δ·I)
观测:  y_t = H_t θ_t + v_t,  H_t = [1, x_t],      v ~ N(0, R)
```

实现要点:
- **内部标准化**:y、x 各自去均值除以标准差后再滤波,使 (δ=1e-5, R=1e-2) 与价格量纲无关;输出时反变换回原尺度;
- **点内输出**:t 日使用**预测态**(只用 ≤ t−1 观测),随后的更新步吸收 t 日观测供 t+1 使用——严格无前视;
- 实测 β_t 标准差约 0.4(围绕训练 β≈0.85),对冲比率随行情自适应。

## 4. 配对筛选(`selection.py`,仅训练期)

1. **粗筛**:全部 C(30,2)=435 组合按收益 MSD(或 |相关系数|)排序,取前 30 候选;
2. **双向 Engle-Granger**:对每个候选分别回归 `y~x` 与 `x~y`,取 p 值更小(EG 统计量更负)的方向——**方向决定 β 是否等于真协整向量**(单向往往估出 1/β);p < 0.05 通过;
3. **半衰期过滤**:OLS 残差的 OU 半衰期 ∈ [5, 60] 天——剔除"回归太快没法交易"和"回归太慢拿着煎熬"的伪对;
4. **贪心去重**:按显著性顺序,每资产只进一个配对(避免重叠配对虚增样本)。

多重检验提示:30 个候选在 5% 水平期望 ~1.5 个伪对通过 EG;半衰期过滤会再淘汰一部分,漏网的由 OOS 止损兜底(Monte Carlo 中查准率长期 >70%)。

## 5. 交易规则(`strategy.py`)

价差:`S_t = log P_j − α − β·log P_i`(β、α 来自训练 OLS 或 Kalman β_t)。

z-score 三种模式:
| 模式 | z 定义 | 特点 |
|---|---|---|
| `rolling` | (S − 均值₃₀) / 标准差₃₀ | 文献基线,参数自适应但滞后 |
| `ou_static` | (S − μ_OU) / σ_eq,训练期一次拟合 | IS 最好,OOS 参数漂移失效 |
| `ou` | 同上,每 60 天用 250 天滚动窗重估 | **点内重估,推荐默认** |
| `ou_kalman` | Kalman β_t 构造 S_t 后同 `ou` | 对冲比率自适应,方差更大 |

仓位规则(含 **disarming** 状态机):

```
空仓且 armed:
  z ≤ −1.75 → 做多价差(+1);z ≥ +1.75 → 做空价差(−1)
持仓:
  |z| ≤ 0.5 → 止盈平仓(保持 armed)
  |z| ≥ 3.5 → 止损平仓,且 disarmed
  持仓天数 ≥ 3×半衰期 → 超时平仓,且 disarmed
disarmed:
  直到 |z| < 1.75(回到入场带内)才重新 armed
```

disarming 的必要性:断裂对的价差发散后 z 长期 > 3.5,若无此机制,策略会在止损次日立即反向重进 → 单对 600 天产生 200+ 笔亏损交易(实测教训,见 [03 · 实验记录](03-experiments.md))。

## 6. 回测口径(`backtest.py`)

- **时序**:t 日收盘算 z_t 定仓位 pos_t → 该仓位承担 t+1 日收益(次日执行,无前视);
- **权重**:美元中性,gross notional = 1:`w_j = 1/(1+β)`,`w_i = −β/(1+β)`;
- **成本**:换手 |Δpos| × 5bp(入场+出场各计一次,双腿含在 gross 内);
- **组合**:所有配对等权(每对 gross=1)平均日收益;
- **指标**:年化收益/波动(252)、Sharpe、Sortino、最大回撤、日胜率、逐笔交易数/胜率/平均持仓/单笔均值(按入场日归属窗口,期末未平仓按 mark-to-market);
- **评估协议**:训练/测试 60/40 切分,IS 与 OOS 指标分列——**任何只报 IS 的数字都不作数**。

## 7. 已知假设与局限

1. 合成器 OU 参数恒定;真实价差的 κ、σ 会漂移,可加 Markov 制度切换扩展;
2. β 在回测期内固定(用于权重),Kalman 模式仅影响信号不影响权重——可扩展为按 β_t 动态再平衡(代价是换手与成本上升);
3. 忽略做空成本/融券费、股息、停牌;gross=1 的归一化忽略了保证金占用;
4. 阈值 (1.75/0.5/3.5) 与 Kalman (δ, R) 未寻优——合成宇宙是做这件事的理想沙盘(训练期调参 → 跨宇宙验证);
5. OU 最优进出阈值有随机控制解析解([2111.02834](https://arxiv.org/abs/2111.02834)),可替换固定阈值。
