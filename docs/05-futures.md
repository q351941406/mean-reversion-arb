## 1. 与股票版的差异

| 维度 | 股票版(run.py) | 期货版(frun.py) |
|---|---|---|
| 价格生成 | 连续价格随机游走 + 植入协整对 | **完整合约带**:现货 + 独立到期网格 + carry + 基差 |
| 合约结构 | 无 | 每品种独立到期间隔(30–60 天错开)、~260 天挂牌窗口,任意时刻同时挂牌多个合约 |
| 成交量 | 无 | 每合约日成交量随剩余期限起落(在品种专属"主力期限"达峰、临交割坍缩)+ AR(1) 噪声,品种活跃度不同 |
| 移仓换月 | 无 | **算法识别**:主力 = 滚动成交量最大者(5 日平滑 + 20% 迟滞),主力切换即换月 |
| 套利载体 | 任意两资产 log 价差 | 跨期(主力~次到期 / 主力~隔月,按量能排名定义)+ 跨品种(主力对主力)+ **三腿因子中性组合**(目标品种对其余两品种 OLS 残差,A-L 式可交易实现),候选全扫描 |
| 流动性 | 无 | **流动性门槛**(薄腿日均量 ≥3 万手)+ **按排名计滑点**(主力 1 跳 / 次到期 2 跳 / 隔月 3 跳) |
| 盈亏 | 美元中性权重 | 手数 × 乘数 × **价格差**(人民币账户口径) |
| 成本 | 一刀切 5bp | 每手手续费(元)或成交额万分比 + 排名化滑点 |
| 资金与风控 | 无杠杆 | 保证金预算 90% 等分×利用率调整 + 每槽 15% 波动率上限 + 账户峰值偿付检查 |
| 配对发现 | MSD + EG | ADF/双向 EG + 稳定性门槛 + 半衰期 + 波动下限 + **流动性门槛** + 多样性约束 |

## 2. 期货化合成器(`futures.py: simulate_futures`)

**期限结构**(品种 c,j 号合约,τ=剩余交易日):

```
log F_c(t, E_j) = log P_c(t) + τ_j(t)·k_c(t) + u_{c,j}(t)
```

- `P_c`:现货对数价(市场+行业因子、GARCH 波动聚集、t(5) 厚尾、跳跃);
- `k_c(t)`:净持仓成本 carry,慢速 OU(半衰期 120 天);
- `u_{c,j}(t)`:各合约基差噪声——**健康品种**(70%)为快速 OU(半衰期 8–18 天)→ 跨期价差平稳;**结构性品种**(30%)为随机游走 → 不回归,算法必须自己剔除;
- **合约带**:品种 c 的 j 号合约到期日 `E = offset_c + step_c·(j+1)`,step_c ∈ {30,40,60} 按品种不同、品种间错位;挂牌窗口 260 天;τ<10 天退出主力候选(交割月)。

**成交量模型**:

```
V_cj(t) = A_c · g(τ) · exp(AR(1) 噪声),  g(τ) = exp(-(log τ - log τ*_c)²/2σ²) · 交付坍缩项
```

τ*_c ∈ [45, 70] 天(品种专属"主力期限"),A_c 为品种活跃度(10–80 万手/日),交付坍缩在 τ→0 时成交量指数衰减。**主力判定**:5 日平滑成交量最大者,挑战者须比现任高 20% 才切换(迟滞),主力切换即换月——样本内各品种换月 8–34 次,频率与真实市场同量级。

**植入跨品种对**:`log P_b = α + β·log P_a + w`(w 快速 OU),作为跨品种发现的 ground truth。

## 3. 算法发现(不预设交易什么合约)

交易哪两个/三个合约由**量能算法**给出:跨期候选 = (主力, 主力之后第一个到期)与(主力, 隔月),换月时整个腿对顺延一个到期档,价差不翻符号;跨品种候选 = 各品种主力合约两两组合(66 个,无行业预过滤);**三腿组合候选 = 同板块三品种,目标品种对其余两品种做 OLS,残差即"剔除板块共同因子后的错定价"——这是 Avellaneda-Lee 式因子中性在只有可交易腿约束下的实现**(每个板块 3 个目标共 12 个)。共 102 个候选。

五道闸门(仅训练期):

1. **流动性门槛**:最薄腿训练期日均成交量 ≥ 3 万手(低活跃品种的远月腿会被自动剔除);
2. **平稳性**:跨期 ADF;跨品种双向 EG 取更显著方向;三腿用残差 ADF——双回归量的残差 ADF 临界值偏宽松,故三腿用**更严的 p<0.01**;
3. **稳定性门槛**:训练期前后两半 ADF 均须 p<0.10(三腿 0.15——半样本功效低)——单次 ADF 会被结构性品种蒙混(AL 曾 p=0.003 过闸;黑色三腿 HC~RB~I 残差半衰期 644 天被正确拒绝);
4. **半衰期 ∈ [5,60] 天 + σ_eq ≥ 0.15%**;
5. **组合约束**:每品种 ≤1 跨期槽 + ≤1 非跨期槽;跨期槽 ≤5;**最优三腿组合保留 1 个非跨期槽位**(跨类型多样化的组合管理规则);共 ≤8 槽。

**信号序列用后复权(调整)价差**:换月会使拼接价差水平跳变(基差噪声换了一组),直接对原始拼接序列估计 OU 会得到跨世代混合的 μ,z 系统性偏差——这是 v2 调试中胜率 0% 的根源。做法:信号用"跳变拼接后的连续序列",**PnL 仍按原始双腿/三腿的真实价格差计算**。对冲比率在原始序列上估计(世代跳变类似固定效应,几乎不影响斜率)。

## 4. 资金、风控与交易规则

- **交易**:|z|≥entry 入场、|z|≤exit 平仓、|z|≥3.5 止损(disarming)、3×半衰期超时强平;换月前 1 后 2 天强制空仓;次日执行;
- **仓位(三层,全部点内)**:保证金预算 90% 等分 × 利用率调整定杠杆 → 每槽资本年化波动 ≤15%(训练期估计)→ 账户峰值保证金 >100% 全局缩放(实测峰值 ~54%);
- **成本**:换手 ×(每腿手续费 + 排名化滑点)× 手数,双边;跨品种手数按 `β×乘数×价格水平比` 取整;
- **盈亏**:`手数 × 乘数 × 价格差`(价格差 = exp(px_t) − exp(px_{t-1}),**不是对数差**——见第 6 节教训 6)。

## 6. v2 重构中的两个新教训(都已修复)

5. **排名腿会抖**。最初跨期腿按成交量排名(主力/次主力/第三)定义,量能噪声让排名在接近的合约间频繁翻转——一个品种 1500 天"换月"292 次(每 5 天一次),换月窗口封掉 78% 的交易日,手续费吃光一切(胜率 0%)。修复:主力判定加 **20% 迟滞** + 5 日平滑,换月降到 8–34 次;腿对从"排名 1~2"改为"主力~其后到期",换月时腿对顺延、价差不翻符号。
6. **对数差 ≠ 价格差**。重写回测时 PnL 误用 Δlog(≈0.005)当价格差(真实 ΔP ≈ 5000×0.005 = 25 元),价差盈亏比手续费(11 元/笔)还小 200 倍 → 每笔交易"稳定亏掉手续费"(平均 -2.5bp,胜率 0%)。修复:ΔP = exp(px_t) − exp(px_{t-1})。**教训:账户层的每个量必须有明确量纲(CNY/点/手),单位错误在 Sharpe 上表现为"稳定的负边际",极易误诊为"策略无效"。**

(v1 阶段的教训 1–4——论文公式 OCR 错误、止损 disarming、双向协整回归、训练期 Sharpe 无法区分真假槽位——见 [03 · 实验记录](03-experiments.md)。)

## 7. 诚实警示

1. 健康跨期价差的均值回归仍是构造保证的;真实市场的微观结构噪声、涨跌停、交割月限仓、逼仓未建模;
2. 收益对杠杆/手数可分性假设敏感;年化 6.5–9.1% 建立在保证金预算 90% 上;
3. 成交量/主力行为是参数化仿真,非订单簿撮合;主力换月规则(迟滞 20%)是简化版,真实规则各交易所/软件不同(持仓量双高切、成交量大者等);
4. 结论到"**更真实的期货语义下,管道+发现算法+资金风控端到端可盈利**"为止,数字不可外推。

## 8. 接真实数据的改造点

1. **合约数据**:分月合约日线 + 成交量/持仓量 → 复现 `logF / volume` 结构;主力序列直接用算法从成交量识别(与仿真同一套 `rank_idx` 逻辑);
2. **规格表**:交易所参数替换 `_SPEC_TABLE`(乘数、最小变动价位、手续费含平今、保证金梯度、真实到期间隔如 1/5/10 月);
3. **到期日历**:真实到期月份替换 `expiry_step`,其余零改动。

筛选(含三腿)、信号、后复权、仓位、回测代码零改动——真实数据只做插拔。
